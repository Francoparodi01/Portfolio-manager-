# Find Opportunities

## Workflow

1. Read the current portfolio and cash context.
2. Run the read-only opportunity scan.
3. Prefer candidates with explicit current evidence rather than narrative appeal.
4. Use Decision Lab evidence when available to distinguish signal strength from demonstrated edge.
5. State invalidators or missing evidence when material.

## Verification

A candidate is not an executable recommendation merely because radar ranks it highly. Do not claim superiority to HOLD unless the compared evidence supports it.
